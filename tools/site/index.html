Mac 提示“无法验证开发者”怎么办
  1. 解压后把「羊大侠 · 月下试炼」拖进「应用程序」。
  2. 双击打开，看到提示后点「完成」。
  3. 打开「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」。
也可以在终端运行：xattr -dr com.apple.quarantine "/Applications/羊大侠 · 月下试炼.app"
Windows 提示“已保护你的电脑”怎么办
  1. 解压 zip，双击 YangDaxia.exe。
  2. 出现蓝色提示时，点「更多信息」，再点「仍要运行」。
