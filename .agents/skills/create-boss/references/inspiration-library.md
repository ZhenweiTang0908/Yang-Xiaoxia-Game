# 灵感参考库

这是起点，不是清单，也不需要全部看。每次设计时按“跨至少四种媒介”的要求挑选，并实际搜索（招式表、帧数据、拆解视频、影评、原著原文、武术讲解），再至少补充两部库外的作品或现实来源。

每条后面的提示只是“可以从这里看什么”，不是要照搬的招式。本游戏是 2D 横版平地竞技场，主角有近身连斩、搓招、弓、翻滚与完美闪避、变身和召唤哥哥，所以优先看**单挑、可读的身体动作、攻防节奏**，少看依赖 3D 镜头或复杂地形的设计。

## 一、动作游戏

1. **艾尔登法环 Elden Ring**：玛莲妮亚的水鸟乱舞（多段连击中的空隙）、拉塔恩的引力与流星（大体型的压迫）、梅瑟莫的火与蛇、葛弗雷从王到“霍拉·路”的身份转换。
2. **只狼 Sekiro**：架势条与弹刀的攻防对话、危字提示的不同回答（跳、识破、闪），苇名一心多阶段的武器变化，护法巨猿断头后的转变，雷反。
3. **黑神话：悟空**：二郎神、黄风大圣、虎先锋、亢金龙等，看中国神怪角色怎么转化成招式；定身、变身、棍势的克制关系。
4. **黑暗之魂 3**：无名王者从骑龙到落地、奴隶骑士盖尔的狂乱节奏、修女芙莉德三阶段。
5. **血源诅咒 Bloodborne**：路德维希从野兽到持剑骑士、玛丽亚的血焰、科斯孤儿的狂暴，看“野性和剑术”的切换。
6. **仁王 2**：妖怪与武士的结合、气力（Ki）的消耗与恢复，看日本神怪的招式化。
7. **卧龙：苍天陨落**：化解（Deflect）为核心的攻防，三国武将的招式性格。
8. **匹诺曹的谎言 Lies of P**：延迟攻击的利弊（玩家常批评过度延迟），可以作为反面参考。
9. **战神（2018 / 诸神黄昏）**：女武神各有主题的招式组，以及同一套动作在不同角色身上的变奏。
10. **鬼泣 5**：维吉尔，看高机动角色的瞬移、幻影剑和挑衅节奏。
11. **对马岛之魂**：一对一武士决斗的仪式感、对峙与一击。
12. **剑星 Stellar Blade**：完美格挡与闪避的反馈。
13. **师父 Sifu**：真实功夫动作（白眉拳）、结构条、环境道具。
14. **怪物猎人（世界 / 崛起）**：怪物的动物行为（威吓、进食、疲劳、愤怒），以及部位破坏改变招式。
15. **旺达与巨像 Shadow of the Colossus**：Boss 本身是场地。
16. **Furi**：整个游戏只有 Boss 战，弹幕阶段和近战决斗阶段交替，每个 Boss 都有清楚的人设和台词。

## 二、2D 与横版作品（和本游戏最接近，必看几部）

17. **空洞骑士 Hollow Knight**：螳螂领主（先一人、敬礼、再两人）、梦魇之王格林的舞蹈节奏、纯粹容器、假骑士。看横版平地上的跳跃、下劈和墙角问题。
18. **空洞骑士：丝之歌 Silksong**：蕾丝等高机动剑士，看更快的横版剑斗。
19. **九日 Nine Sols**：道朋克风格、以格挡为核心的 2D 战斗，几位 Boss 的身份和招式都有东方神话来源。
20. **神之亵渎 Blasphemous 1 / 2**：宗教意象转成 2D 招式。
21. **终焉之莉莉 / 木兰 Ender Lilies / Ender Magnolia**：被击败的 Boss 变成主角的召唤物，看招式的“二次使用”。
22. **茶杯头 Cuphead**：极致的可读预兆、每个阶段完全换一种玩法。
23. **死亡细胞 Dead Cells**：横版快速战斗中的前摇和颜色提示。
24. **铲子骑士 Shovel Knight**：黑骑士等“镜像对手”，看同类角色如何做出不同。
25. **洛克人 X / 洛克人 ZERO**：每个 Boss 的一个核心机制和弱点武器的关系。
26. **恶魔城：月下夜想曲 / 血污：夜之仪式**：大量 2D Boss 的体型与动作选择。
27. **波斯王子：失落的王冠**：2D 下的时间、传送和追逐。
28. **武士刀零 Katana Zero**：一击必死下的反应节奏、Boss 的叙事化。
29. **胧村正 Muramasa**：2D 日式手绘角色的动作美感。
30. **奥日与萤火意志**：Boss 战和逃跑段落的结合。

## 三、格斗游戏与 MOBA

31. **拳皇 KOF**：八神庵、草薙京的招式性格；大蛇、卢卡尔等“SNK Boss”读输入、超强判定的设计，是**反面教材**。
32. **街头霸王 6**：帧数据、确反、立回（neutral）与驱动系统，看“距离”本身怎么成为一种招式。
33. **侍魂 Samurai Shodown**：重斩的高风险高回报、一刀定胜负的张力。
34. **罪恶装备 Strive**：极强个性的角色，每个人的动作都是性格。
35. **铁拳 Tekken**：横移与纵深，以及不同武术流派的身体特征。
36. **拳无虚发 Punch-Out!!**：每个对手的预兆都是一个性格表演，最适合学“预兆即人设”。
37. **英雄联盟 League of Legends**：亚索的风墙、劲夫的反击风暴（Jax）、菲奥娜的破绽与反击、劫的影分身、锐雯的连招、李青的回旋踢、潘森的盾与枪。看如何用少数技能讲清一个角色。
38. **永劫无间 Naraka**：振刀（蓝光霸体与振刀的克制关系），中国武侠动作的游戏化。

## 四、电影与剧集

39. **功夫**（周星驰）：火云邪神的蛤蟆功和接子弹，琴魔用琴声化成刀剑，包租婆的狮吼功；看夸张、喜剧感与威胁感怎么同时存在。
40. **复仇者联盟 3 / 4**：灭霸使用不同宝石时的招式变化，看一个角色如何用“工具”分段，以及战斗如何利用环境。
41. **卧虎藏龙**：竹林、屋顶追逐、青冥剑；玉娇龙与俞秀莲换兵器的那一场。
42. **英雄**（张艺谋）：雨中棋亭的对决、想象中的打斗、以色彩分章节。
43. **一代宗师**：宫二与马三在月台上的对决，叶问与宫宝森“掰饼”的比试，看“点到为止”的武术哲学。
44. **叶问 / 叶问 2**：咏春的贴身节奏，叶问与洪拳宗师在桌上的比试。
45. **杀破狼 SPL**：甄子丹与吴京在小巷里的警棍对短刀，看长短兵器的距离之争。
46. **精武英雄**：李连杰与仓田保昭的对决，借力与卸力。
47. **醉拳 2**：醉拳的失衡与假动作，看“看似破绽其实是攻击”。
48. **黄飞鸿之男儿当自强**：黄飞鸿与纳兰元述的梯子对决，看场地道具。
49. **新龙门客栈 / 东方不败（笑傲江湖 II）**：飞针、刀光、身法飘忽，看“看不见的武器”怎么让观众读懂。
50. **十面埋伏 / 刺客聂隐娘**：飞刀与竹林伏兵；聂隐娘的静与一瞬。
51. **用心棒 / 椿三十郎 / 座头市**（日本时代剧）：对峙的静止、一刀分胜负，盲剑客听声辨位。
52. **疾速追杀 John Wick / 突袭 The Raid**：现代动作片的连贯编排、走位与换枪换刀的节奏。
53. **黑客帝国**：史密斯特工的复制、子弹时间。
54. **星球大战 I：幽灵的威胁**：达斯·摩尔的双刃光剑，三人决斗中的场地分隔。
55. **指环王**：炎魔与戒灵，看巨大体型和恐惧感的营造。

## 五、古典小说、神话与武侠

56. **西游记**：七十二变、身外身法（拔毛变猴）、金箍棒变大变小；红孩儿的三昧真火、铁扇公主的芭蕉扇、金角银角的紫金红葫芦（叫名字就收人，和本游戏的葫芦有天然联系）、牛魔王（与牛大侠的关系可以利用）。
57. **水浒传**：林冲的枪、鲁智深的禅杖与倒拔垂杨柳、武松打虎（读老虎的“一扑一掀一剪”）、花荣的箭、张清的飞石、燕青的相扑、公孙胜的法术、李逵的双斧。一百零八人里有大量“兵器即性格”的素材。
58. **三国演义**：关羽的拖刀计（假装败退再回身一刀）、张飞长坂桥一声喝退曹军、赵云七进七出、吕布与三英。
59. **封神演义**：哪吒的风火轮、乾坤圈、混天绫，杨戬的天眼与变化，各种法宝的“规则型”能力。
60. **金庸武侠**：降龙十八掌（亢龙有悔，留有余力）、独孤九剑（攻其必救、无招胜有招）、乾坤大挪移（借力反弹）、凌波微步、六脉神剑、打狗棒法的“缠封绊戳”。
61. **古龙武侠**：小李飞刀“例无虚发”，西门吹雪与叶孤城决战紫禁之巅，看“一招”的分量和等待的张力。
62. **山海经 / 聊斋志异**：异兽和精怪的形体与习性，适合做非人形 Boss。

## 六、动画

63. **大闹天宫（1961）/ 中国奇谭**：中国传统美术风格下的动作与造型，后者的《小妖怪的夏天》《鹅鹅鹅》等短片。
64. **哪吒之魔童降世 / 哪吒之魔童闹海**：神话角色的现代动作设计。
65. **大圣归来**：孙悟空的身段与重量感。
66. **剑风传奇 / 浪客剑心 / 鬼灭之刃**：巨剑的重量、拔刀术、各种“呼吸之型”如何把一套招式做成编号的体系。

## 七、库外的方向（自行搜索补充）

这些方向没有列具体作品，需要自己找：

- **真实武术**：八极拳、八卦掌的走圈、太极推手、形意、螳螂拳、蛇拳、日本剑道与居合、菲律宾短棍、西洋剑、蒙古摔跤、泰拳。
- **戏曲**：京剧武生的起霸、亮相、把子功，川剧变脸。亮相就是天然的预兆。
- **动物行为**：猫科的潜伏与扑杀、螳螂的捕食、鹰的俯冲、蛇的蓄势、羊与牛的顶撞（和主角兄弟有关）、蜘蛛结网。
- **舞蹈与杂技**：舞狮、剑舞、水袖、杂技的平衡与抛接。
- **冷兵器**：流星锤、九节鞭、绳镖、双钩、峨眉刺、朴刀、陌刀，以及它们的距离和弱点。
