# 羊大侠 · 月下同行（v0.2）

Godot 4.7 / GDScript / Compatibility 渲染的三关固定路线横版动作游戏。主角羊小侠按旧版身高的 60% 绘制（52.8 像素），哥哥牛大侠保持旧版主角的 88 像素。主角保留完整像素原画，使用二维网格与解剖引导点补间；头颈保持整块移动，跑跳、落地与三连斩在原画姿势之间插值，攻击对齐伤害时刻。Blender 主角实验资源保留，但不用于当前游戏人物显示。牛大侠仍使用保留原画的二维骨骼。

## 四境连战（当前默认）

「新的旅途」现在是连续四场 Boss 战：守灯石庭（守灯兽）→ 渡影断桥（渡影刀客）→ 噬月祭坛（噬月祭主）→ 断誓骑场（断誓枪骑）。小兵与长地图暂时停用，但敌人、关卡资源（`data/levels/`）和相关代码都完整保留。

- 每击败一个 Boss，月露补满到 2 瓶，并自动习得一式武学：第一战后「破锋」、第二战后「灵火」、第三战后「同心」，不再弹出选择。
- 战间结算页显示获得的武学，点「下一战」继续；死亡只重试当前 Boss。
- 四个竞技场都有多层可下穿平台（`data/arenas/boss_*.tres`）。布景由 `scripts/world/battle_architecture.gd` 分远景、平台后方结构和地面细节三层绘制，不带碰撞。

## 试玩

- Mac：打开 `builds/macos/羊大侠 · 月下试炼.app`，或解压 `builds/macos/YangDaxia.zip`。
- Chrome：运行 `试玩网页.command`，访问 http://127.0.0.1:8765 。点击「新的旅途」或「继续」后开始播放音频。通过 HTTP 打开，不能直接双击 HTML。
- Godot：导入 `project.godot` 后按 F5。

旧的一关版本保存在 `builds/archive/v1`。新版使用独立的 `progress_v2.json`，不会读取旧版存档。Mac 与浏览器存档各自独立，浏览器清除站点数据会清除网页进度。

存档采用临时文件替换并保留上一份有效备份；主存档损坏时会自动读取备份。山灯武学层数及尚未完成的选择也会保存，退出后继续游戏不会丢失或跳过选择。正式导出隐藏调试、自由跳关与动画实验入口；开发时可使用编辑器运行或添加 `--dev-tools` 参数开启。

## 操作

| 按键 | 行为 |
|---|---|
| A / D、左右箭头 | 移动 |
| 空格 / W / 上箭头 | 跳跃，提前松开降低跳高 |
| 下箭头或 S + 跳跃 | 从薄平台下穿 |
| J | 三段近战连斩 |
| ↓前 + J | 踏月剑气：向前发出穿透剑气 |
| ↓后 + J | 回风斩：斩击身体两侧 |
| 前↓前 + J | 升龙斩：向上跃起，斩击前上方并破盾 |
| K | 拾弓后射箭；羊灵形态发射穿透幽焰 |
| Shift / L | 闪避；羊灵形态为带伤害的羊角突进 |
| 按住 J 后松开 | 蓄爆：按下先出一刀，继续按住在收招后蓄力，松开释放；至少蓄力 0.32 秒，蓄力期间承受伤害降为 85% |
| Q | 觉醒就绪时主角身边环绕紫白气息，按 Q 变成羊灵，持续 15 秒（结束前 3 秒散出金色余光） |
| E | 召唤牛大侠，第一关结束剧情后解锁 |
| F2 / 右上角「调」 | 战斗参数窗口，含强制牛魔测试 |
| Esc | 暂停 / 继续 |
| M | 全部静音 / 恢复 |
| Enter | 开始、剧情继续、重试或下一关 |

参数面板在 Mac、Web 编译版同样可用：标题页点击「参数 · F2」，游戏中点击右上角「调」，或按 F2。打开时暂停，修改后点「应用并保存」；Esc/F2 返回此前页面。

人形搓招中的「前/后」按起手朝向镜像；例如朝右时剑气为 S→D→J，回风斩为 S→A→J，升龙斩为 D→S→D→J。方向在 0.75 秒内完成，最后方向后 0.3 秒内按攻击；支持斜方向过渡。三招共用 1 秒冷却，可接在普攻命中后的后摇中，不消耗觉醒或战意。手柄用方向键/左摇杆搓方向，再短按近战键。

Android/触屏设备自动显示横屏触控按钮，可同时移动、跳跃、攻击和召唤。切换窗口自动暂停。音乐、音效、环境音分别调节并保存，也可关闭屏幕震动。

牛大侠现有 50 生命，低血量时出牌可变为黑色红眼的四足牛魔，保护与治疗弟弟，之后锁定闪现作战。完整规则与 28 项调试参数见 [牛魔说明](docs/NIU-DEMON.md)。

## 骑士挑战 · 断誓枪骑

标题页提供「骑士 · 马战」完整双阶段挑战与「骑士 · 步战」直接演武；自由跳关也保留最后一行入口。步战入口和自然下马后的死亡重试都从满血步战开始，每次进入固定补满两瓶月露，不改写旅途关卡、山灯、计时或装备。自然下马后的继续挑战计为步战演武，不增加完整双阶段纪录。

- **马战**（2400 生命）：骑枪掠袭、勒马折返、前蹄重踏、后蹄蹬踢、枪柄压击、三步逼阵与回缰挑枪。冲锋只有枪尖结算，承诺后不转向；近身招式会先突进到有效距离。
- **下马**：生命低于一半立即锁定、清除旧攻击并下马。落地尘气固定扣 10 点生命（不受从容模式减免，可致死），并封住葫芦 10 秒；尘气散去再停 1 秒才开始步战。
- **步战**（2400 生命）：长矛测距点刺、枪尾回敲、绞枪架势与反刺、三叠枪气、贯甲进刺、蹬踢接刺、回旋掷矛、旋枪破阵、三折追刺、踏进重挑；弓箭定弦连射、退步连射与追猎三矢。剑招已移除。
- **战怒**：每损失最大生命约 4% 蓄一格，最多三格；换武器与防御不消耗，普通进攻有40%概率保留战怒，其余消耗一格强化。两格时发动幽军降阵：三弓兵、三枪兵、一刀兵缓降落地后各自出手（枪兵、刀兵每击 12）。满三格改为**强化幽军**：增加第四名枪兵和第二名刀兵（后者稍晚出现在主角面前），全部改用鹰形魂箭，枪兵与刀兵每击 14。已取消全屏紫鹰：不再有无法躲避的全屏固定伤害，也不会强制收回牛大侠。强化会改为五道不均匀枪气、五段分别锁向的追刺、加长约 23% 的长枪、六至七发连射与加粗疾光箭，枪击后追加一次性刀 / 枪虚兵。
- **突进伤害**：骑枪掠袭、勒马折返、贯甲进刺、旋枪破阵、三折追刺与踏进重挑的伤害提高 8%，前摇时间不变。
- **弓箭与魂骑**：普通点射四箭、移动连射五箭、扇射三轮三箭，出箭更快且持续锁定到各自放箭前；每次拉弓会在上方召出上半身为骑士、下半身为紫魂的虚像。虚像延迟发出魂箭，实际命中会短暂减速；战怒时改为鹰形魂箭。最多同时保留三个虚像，防止画面失控。
- **枪气**横贯全场、贴地 2–12 像素，翻滚、冲刺、变身与受伤无敌都挡不住，轻跳即可越过。普通三枪使用匀速或慢第三枪；战怒五枪保留各自可跳窗口。
- 弓箭实际命中会封葫芦 3 秒；普通矛击和踏进重挑不额外封印。重复封禁取较长剩余时间。封禁时葫芦落在附近地面，结束后飞回；助战中被封会保存生命、形态与剩余时长。暂停与命中停顿冻结计时。
- 骑士有 12 句离线中文语音与字幕，覆盖登场、步战、下马、重要技能、低血量和败北；普通台词至少间隔 12 秒，不会抢占牛大侠正在播放的语音。
- 骑士没有危险矩形、瞄准线、感叹号或倒计时，HUD 不显示招式名；预示来自身体动作、物理音效、金紫色战怒蓄势与技能特效。血量、突进速度、前摇、攻击伤害倍率、枪气间隔、战怒比例与封禁时长都在 F2 参数面板中。实体箭速度已降低20%，突进加入短暂抬手和淡金色枪杆蓄势。默认攻击伤害倍率为 0.9；下马尘气仍按固定 10 点结算。

## 三关内容

每关四段相连区域、24 个固定敌人及一个 Boss；入口、中段和 Boss 前设山灯检查点。抵达中段与 Boss 前山灯时，世界暂停并从三式武学中选择一项：破锋叠加近战伤害，灵火延长羊灵并强化幽焰，同心延长牛大侠助战并强化卡牌与冲撞。武学可重复叠加，跨关、死亡重试与重新打开游戏都会保留。关卡总长各 16000 像素，无无限刷新、随机地图或强制等待。死亡恢复最近检查点与生命，重置后续敌人，保留弓、葫芦、武学和已完成剧情。

右上角显示当前区域的“敌踪”进度。击败该区域本次生成的全部普通敌人后获得“本段肃清”奖励：恢复最多 12 点生命并增加 20 点觉醒；羊小侠或牛大侠完成最后一击都有效。Boss 不计入敌踪，奖励每次载入只触发一次。

每关结束显示旅途结算卡：本次尝试用时、击败数、区域肃清和本关新增武学。第三关结束后改为整段旅途统计，并列出三系武学的最终层数。暂停、剧情和山灯选择不计入游玩时间；死亡重试会重新开始本次尝试统计。

三关各藏有两枚“月痕”，分布在屋顶和机关上层路线，共 6 枚。首次接触会记录一段月下旅途短句、增加 15 点觉醒并立即保存；月痕跨死亡、切关、关闭游戏和新的旅途永久保留。HUD、标题页和终局结算均显示收集进度，月痕不是通关条件。

标题页或暂停菜单可打开“月痕札记”，回看已经发现的六段旅途记录；尚未取得的条目只显示所在关卡，不会提前泄露内容。札记打开时世界与计时均暂停，关闭后返回原先的标题页或暂停菜单。

设置页提供“标准 / 从容”两种旅途强度。标准模式保持原始战斗数值；从容模式仅将羊小侠承受的伤害降至 70%，不改变敌人生命、玩家输出、奖励或计时，并可在旅途中随时切换。该偏好跨重试、新旅途和重新打开游戏保留。

死亡页会根据最后一次致命伤显示实际败因和一条对应提示，覆盖飞刃、灵弹、横扫、扑击、裂隙、雷击、落雨、长息、关卡地刺、祭阵与坠落；未知来源使用通用说明。重试后旧败因立即清除，不写入存档，也不改变战斗数值。

标题页与结算页可打开“旅途簿”。它按标准、从容两种强度分别保存三关的完成次数、最快用时、最高击败和最高肃清，并结合每关月痕显示“已通关 / 四境肃清 / 双月痕”印记。记录跨新旅途与重新打开游戏永久保留，旧存档会从空记录安全开始。

标题页的“新的旅途”会在存在关卡、山灯、装备、剧情或武学进度时先显示确认页，分别列出将重置的途中进度与会永久保留的月痕、旅途簿和设置；取消、Esc 或手柄返回均不会修改存档。全新存档会直接开始，终局“重新启程”也保持一步重开。

1. 月下山门：跳台、断桥、拾弓、战意与觉醒教学；守灯兽三招。
2. 雾林古渡：混合近战与远程敌群；渡影刀客七招，半血改变组合。
3. 幽钟祭坛：精英与符阵敌群；噬月祭主十招，65% 和 30% 生命变换阶段。

Boss 跨过生命阈值时会进入 1.25 秒阶段转换：旧招式和该 Boss 留在场上的攻击会被收束，Boss 短暂无伤，玩家可重新站位；转换后再留 0.65 秒才开始下一招。守灯兽的“灯火暴走”、渡影刀客的“影刃加速”，以及噬月祭主的“月蚀初临 / 噬月终仪”都会在血条下明确显示，暂停会冻结转换计时。

翻滚的 0.23 秒保护窗口内如果真正与敌方飞行物或伤害区域相交，会触发“踏月闪”：本次翻滚最多奖励一次，增加最多 15 点战意和 12 点觉醒，并显示实际获得值。向前冲刺以及出生、受伤、变身等普通无敌不会触发该奖励。

每段旅途携带两瓶“月露”，可按 R、手柄方向上或触屏“露”恢复最多 35 点生命。满生命或月露用尽时不会误消耗；山灯与切关会补满，死亡重试和重新打开游戏保留剩余数量。

雾林古渡有两段方向相反的雾流，会温和推动角色并改变跳跃与交战距离；幽钟祭坛设置三处周期祭阵，阵纹先亮起预警，随后短暂造成伤害。环境机制随暂停冻结。

八类敌人：石精、游魂、镇门石卫、扑击山魈、夜翼蝠、飞针客、盾角兵、引魂师。镇门石卫在后两关为普通重型敌人。

羊灵使用独立羊头、弯角与幽刃动作，生命与人形共享。三段连斩各有不同的出刀顺序（横斩、劈斩、回旋大斩），第三段附带斩波。羊灵的近战与幽焰出手速度是人形的 1.3 倍、伤害 1.4 倍，蓄爆伤害 1.5 倍；幽焰只看冷却（约 0.37 秒），不必等前一发飞出屏幕。羊角突进冷却 1 秒，蓄爆击杀少量回血。

受击会先后仰（背后中招则前扑），白光一闪再缓缓回正；回正动作比 0.22 秒的硬直更长，但不额外锁操作。三式搓招各有身法：踏月剑气压低前冲并带残影剑弧，回风斩整身回旋，升龙斩蓄身后金色螺旋随人升起。

羊灵与人形的旧版 2D 图集由 `tools/repack_atlas.gd` 重新打包（`*_clean.png`），修复了动作超出格子被裁切、相邻帧残片混入的问题；原图保留。

牛大侠是两臂普通人，保留眼镜、嘴下痣与齐肩绿白双色发，穿简洁深色外套，自动使用飞牌、三叶散牌、回环牌及缚灵牌阵。小葫芦跟随主角；召唤时停下放大、开口、卡牌旋出，哥哥显形跨出。召唤不锁定主角。出场约 1.2 秒，随后助战 30 秒，离场约 0.8 秒，离场结束才进入 100 秒冷却。暂停冻结计时，死亡/切关清理实例，检查点重试就绪。

## 资源与工程

- 六首原创音乐：三首探索曲各 96 秒，三首 Boss 曲各 64 秒，切换淡入淡出。
- 敌人有 28 套招式声音身份，蓄势、出手和实际命中共 84 条 CC0 Foley 音效；预警、敌方攻击、受击和普通近战使用独立声部，群体区域限频，受击时短暂压低音乐。
- 人形待机/跑动及每段斩击均 8 帧，第三段使用独立动作图集；羊灵、哥哥及敌人各有独立动作图集。
- 物理使用 CharacterBody2D，跳速 520、重力 1080，土狼时间 120ms、跳跃缓冲 150ms。
- 模块分为角色、战斗/投射物、敌人/Boss、召唤、地形、音频、存档和 UI；地图和招式以 Resource 配置。

`tools/make_levels.py` 离线编译固定地图资源；运行时不生成随机地图。`tools/make_audio_v2.py` 生成原创音频，`--sfx-only` 仅生成音效。图像来源和提示词见 `docs/ART.md`。字体为 OFL 授权 Noto Sans SC，许可在 `assets/art/FONT-LICENSE.txt`。

`tools/make_enemy_audio.py` 使用现有 CC0 swishes 和 Kenney Impact 录音重建敌人招式音效及声音目录。音频身份在弹丸/区域生成时保存；无敌与闪避不播放实际受击声。试听与来源清单位于 `builds/qa/audio/enemy-attack-preview.wav`、`enemy-attack-showcase.wav` 和 `enemy-audio-manifest.json`。


具体结果与尚未达成的验收项见 `docs/VALIDATION.md`。目标每关首次 10–15 分钟目前未经真实玩家计时确认；带受击保护的自动路线测试不能作为难度或时长验收。Boss 的所有招式已有不同预兆与轨迹，公平性及动画手感还需要正常游玩的反馈与调优。

牛魔现在变为四足黑牛，羊小侠骑在背上；牛魔锁定后闪现至敌人身后冲撞。已移除六臂、牛人下肢和三叉戟。规则与调试说明见 `docs/NIU-DEMON.md`，新美术见 `docs/SIMPLE-BROTHER-ART.md`。

## 开发模式自由跳关

使用编辑器运行或添加 `--dev-tools` 参数后，标题页、暂停/死亡界面可点击“自由跳关”，游玩中也可点击右上角“跳关”。三关均直接开放，每关可选入口或倒数第二区域（第 3/4 区域）。跳关后满生命，配备弓箭与葫芦；会保存该入口，死亡重试及继续游戏恢复到所选区域，抵达后续山灯后使用新的检查点。正式导出不显示这些入口。

网页存档按浏览器站点（含端口）独立保存；建议持续使用同一个地址。跳关不依赖已有存档，首次打开也可以直接选择。

Mac窗口默认1600×900，屏幕较小时自动适配可用区域的92%。允许拖动边框调整，最小640×360，游戏画面保持16:9比例。

## 普通攻击声音
