# 连续动作样片

tests/action_timeline.gd 将现有实验中的起跑、空中收腿、落地相位衔接、停步与三连斩组合成一条固定时间序列。共享同一个二维 rig 与接触状态，120 Hz 推进。练习靶固定在世界坐标，随镜头相对移动；三连斩的伤害仍由剑刃扫掠触发。

hero_action_capture.gd 输出 builds/qa/action-sequence.mp4（4.2 秒），包含脚步、起跳、落地、三次破风与三次石质命中声音。音轨由时间线事件写入 action-audio.json，再通过 mux_event_audio.py 合成。

action_sequence_audit.gd 验证：1 次起跳、1 次落地、3 次挥剑、3 次目标命中、5 次脚步，无重复采样事件，无超长锁脚释放。原生录制同样得到 13 个声音事件、3 次命中、0 次锁脚释放。检查 action-frames/0160.png 的攻击阶段。

这是第一份将这些实验动作串联的有声样片，尚不代表最终美术验收。仍采用预定跳跃轨迹与输入序列，并未与前一份 CharacterBody2D 平台测试合并。动画切换、脚部轮廓、命中停顿与落地细节仍需实际游玩检查；正式游戏未替换角色，未重新导出客户端。
