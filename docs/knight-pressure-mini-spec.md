# 骑士追击、远程与步战续战

## Goal
让断誓枪骑成为高于第三关目标强度的追击型战士，弓箭与长矛覆盖近中远距离；支持步战直接挑战及失败续战，并配中文语音字幕。

## Expected Behavior
- 标题直接选择马战完整挑战或步战演武。自然下马后失败，默认从满血步战重试；所有挑战进入/重试固定补满2个月露，生命与助战重置。直入/续战不触发下马尘气，也不混入完整双阶段纪录。
- 取消剑招。近战仅在有效距离选用；开招后若对手离开，先有可读追步/冲刺再出手，不能凭空远距离扣血。不再慢走追人。
- 长矛新增回旋掷矛（可见去程/回程、每程每目标至多一次）、旋枪破阵（明显起手后高速旋枪突进）、三折追刺（三次分别准备、分别锁向的突进）及踏进重挑。保留两种三枪节奏，均只在枪气释放瞬间结算全场低位判定。
- 弓箭加入移动预判点射与三矢封路，每轮锁定后不追踪；可用跳跃/翻滚/改变移动方向避开。弓箭实际命中封葫芦3秒，掷矛和普通矛击不额外封印。
- 远处优先突进/掷矛/弓箭，近处近战/架势反击，空中采用高位追击。每个大招有明确起手、独立接段提示和至少0.45秒收招。持续逃跑也会遭受有效攻击，但不靠取消前摇、无限跟踪或无范围伤害。
- 增加旋枪金属弧、残影、枪锋拖尾、回旋武器、箭尾与地面尘屑，遵循已有手绘2D画风。中文台词用于登场、下马、重要技能、低血量和败北；普通技能至少12秒语音间隔，不抢占牛大侠语音。
- 新追击距离、速度、前摇与伤害接入参数面板。全部骑士攻击使用0.9伤害倍率，下马尘气保留固定10点。

## Open Questions
None；依用户授权按推荐实现。

## Verification Target
阶段入口/续战/月露稳定补给与旅途隔离；近远选招和真实移动；突进连续碰撞/锁向/每段一次；掷矛去回命中/回收/死亡取消；移除剑；枪气及封印骑乘回归；真实语音播放/字幕/节流；实机视觉与原生/Web编译验证。以同一逃跑脚本对比第三关首领的攻击接触与压制效果，记录数值与设计局限。

## 本轮追加：战怒与魂骑
每损失最大生命4%蓄1格，最多3格，下一次实际攻击消耗1格；换武器/防御不消耗。强化五段追刺与五道变节奏枪气，各自锁向/抬手，枪气间隔不低于完整跳跃间隔。强化弓箭1100px/s、加粗发光，普通弓箭780px/s；普通点射4箭、移动连射5箭、扇射3轮×3箭，强化分别6/7/5轮。每次出箭伴随一次延迟魂骑补射（同一扇射轮仅一个虚像、最多同时3个），强化魂箭化为鹰；魂箭实际命中轻缓速22%、约1.4秒，保留跳跃翻滚；强化长矛加长约23%，追刺后追加一次性刀/枪虚兵。虚像与虚兵是攻击特效，不是持久小兵。
