# 羊小侠连续动画样片

2026-09-12。范围是主角人形，尚未重做羊灵、哥哥或敌人的动画。

## 制作方式

Godot Skeleton3D 的 17 根骨骼驱动固定比例的身体与武器网格；原人物插画脸部作为头骨上的贴图面片，保留辨识度。不是完整的写实头部雕刻。SubViewport 以 192×160 连续渲染，游戏中角色高度仍为 52.8 像素。运行时保留三维骨骼，使状态切换可以真正混合姿势，不对两张图做透明度渐变。

运动采样位于 scripts/animation/hero_motion.gd。跑步使用两节腿部逆运动学，支撑脚高度保持一致，步幅与移动速度关联。状态切换使用 75–100ms 姿势承接；三连斩分别为 0.38/0.41/0.49 秒，有效伤害时刻为 0.15/0.17/0.22 秒。脚步声由步态触地阶段触发，挥剑声提前有效帧约 35ms。人形弓箭在拉弓约 130ms 后离手，受击取消尚未释放的箭。

标题页「动画对比」提供同一动作流程的新旧画面对照、暂停、半速和游戏内版本切换。录像为真实 Godot 渲染，未通过补帧软件处理。该对比页本身不模拟攻击命中声音；关卡中的音频系统继续工作。

## 编辑资源

- art_source/hero/yang_xiaoxia.blend：Blender 5.2.1 工程，包含模型、骨骼、动作、相机、灯光和打包贴图。
- art_source/hero/yang_xiaoxia.glb：交换文件。
- scenes/animation/hero_rig.tscn：Godot 可编辑模型场景。
- assets/animation/hero_animations.tres：12 个 60Hz 采样动作，可由 AnimationPlayer 播放。
- tools/export_hero_rig.gd：从动作源生成场景及动作。
- tools/export_hero_glb.gd：导出 Blender 交换文件。
- tools/prepare_blender_hero.py：用 Blender 内置 Python 创建编辑工程。

当前游戏仍以 GDScript 动作源为准。Blender 工程是同一套模型与动作的可编辑交付；在 Blender 修改后的动作不会自动覆盖运行时采样器，需要再次导出并接入。

## 验证

- tests/animation_motion.gd：10 项通过；支撑脚、固定腿长、三段攻击时刻、30/60/120 FPS 数值采样、17 骨骼、12 动作和 AnimationPlayer 实际驱动。
- tests/integration.gd：53 项通过，含跳台、近战有效帧、变身、召唤时序、三关 Boss 与音频。
- tests/gamepad.gd：31 项通过；未连接实体手柄，使用模拟输入。
- 实际 Godot 原生窗口录制了完整对比循环；Chrome 加载新版成功，关卡可显示主角骨骼人物。
- Mac、Web 已重新导出。Android 保留配置，当前环境缺少 Android build-tools，未验证真机。

这轮验证不等于完成了长时间帧率性能测试，也不代表其他角色已达到相同动画质量。

## 连续性打磨（第二轮）

跑步周期从 0.28 秒调整为 0.36 秒，保留与移动速度匹配的支撑阶段；持剑手减少大幅摆动。起跳逐渐收腿，下落逐渐伸腿，落地按压缩—回弹—稳定的时间曲线变化，移动时提前承接跑步。

第一、第二斩在有输入缓存时分别于 0.27/0.29 秒接入下一斩，单次攻击仍保留完整收势。攻击视觉时钟在渲染帧之间连续推进，并受物理时钟和命中停顿约束。剑光以 120Hz 采样实际骨骼剑尖的弧线，105ms 内消散；新骨骼人形不再叠加旧版独立圆弧特效。弓箭收手改为连续曲线。

新增 tests/animation_chain.gd：6 项通过，覆盖两次连招提前承接、末斩完整恢复及跳落地姿势变化。动画数值与导出资源检查 10 项通过。快速退出时仍有 Godot ObjectDB 资源清理警告，未把它计为渲染或功能验证通过。

## 羊小侠模型轮廓修订

针对直筒上衣、突出的胯部椭球和硬管四肢，替换为沿截面塑形的服装/肢体网格：肩部渐收、衣摆覆盖腰部连接、袖口与前臂/小腿有明确粗细变化，缩小肘膝和脚部块体。头部略缩小，保留原人物脸部画法。此次仍是三维身体＋二维脸部的混合方案，未声称完成写实头部雕刻或全身蒙皮重拓扑。

对比图：builds/qa/model/comparison-idle.png、comparison-slash.png。同一姿势、光照与相机下对照修改前后。检查站立、跑步、挥剑；17骨骼和12动作保持兼容，animation_motion.gd 10项通过。Blender与Godot编辑源同步更新。
