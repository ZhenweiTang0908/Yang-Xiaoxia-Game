# 二维原画补间

当前游戏主角完全由二维图片和 ArrayMesh 显示，不使用三维模型或 SubViewport。保留用户认可的原画身份。

hero_2d_pose.gd 为各姿势指定衣领、骨盆、双手、双脚的源图坐标。hero_2d_skin.gd 创建 24×32 网格，按引导点影响权重补间顶点。脸部与头颈区域整块平移，避免五官被分别拉伸。hero_visual.gd 按动作时间插值目标引导点，状态切换用 90 毫秒过渡，挥剑第四姿势对齐原伤害时间。暂停与受击停顿冻结动画。

40 张普通动作和 8 张上挑动作导出为独立透明图。裁切向左右扩展后保留人物主体连通区域，避免原图格截断剑尖和带入邻帧残片。工具：tools/clean_hero_atlas.gd。动作对比窗口左侧旧图集、右侧新网格，提供慢速和暂停。

这是保留原画的网格补间，不是新绘制的逐帧动画，也不是分层完整骨骼角色。原画切换仍承担大幅转向与遮挡变化，不能自动解决原画自身的五官和手臂差异。后续需在这个外形基础上补画特殊转折姿势，而不是更换三维人物。

验证：二维网格、无三维视口、10 类状态有限数值、中间腿部位移、状态切换衣领连续、三段攻击时间同步共 17 项；实际连招衔接测试通过。比较视频：builds/qa/hero-2d-comparison.mp4。
