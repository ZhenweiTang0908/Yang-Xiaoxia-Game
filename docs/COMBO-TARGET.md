# 剑刃命中测试

tests/blade_sweep.gd 按相邻姿势的剑根位移与转角细分扫掠，检查剑段与圆形测试目标的距离。仅在三段有效时间窗内检查，同一段命中后不重复扣血。

combo_target_audit.gd 在 120 Hz 下三段都能命中中心 (134,135)、半径 18 的近处目标；中心 (500,135) 的远处目标没有误判。该几何检查只覆盖圆形单目标，不代表现有敌人碰撞形状或正式战斗系统已改造。

hero_target_capture.gd 使用低细节石质练习靶，真实扫掠命中触发短暂变亮、两条碎屑和石质命中音效。60 FPS 捕获结果为 3 次命中，生命 100→10（24+30+36）。未添加无命中时的受击声。target-audio.json 保存各次事件的实际录制帧，tests/mux_event_audio.py 使用现有 WAV 资源制作离线同步音轨。

输出 builds/qa/combo-target.mp4。这是视觉与命中对齐实验，尚无敌人行为、受击停顿、移动取消或正式游戏接入；练习靶不是新增关卡美术。
