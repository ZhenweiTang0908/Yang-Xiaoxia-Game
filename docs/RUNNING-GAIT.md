# 按实际跑速验证步态

tests/hero_running_gait.gd 从现有角色图集读取实际缩放 0.25384615，保持游戏速度 225。完整周期 0.4 秒，单腿支撑占比 0.16923077，原图坐标步幅 60；其余时间前摆抬脚，两腿之间存在腾空阶段。并未修改游戏移动速度。

初次大步幅实验产生 5046 个翻转三角形。跑步模式改用以髋部为中心、随半径渐变的旋转，替代位置线性混合；下半身纹理条带细分以正确采样弯曲。再次检查 120 帧：翻转三角形 0，76 帧双脚不处于支撑阶段，支撑地面高度误差 0，按实际速度计算支撑单帧水平漂移约 0.0000011 游戏像素。

这仅证明该实验的支撑速度与网格方向。running-bend.png 实际检查仍见裤腿轮廓尖角、姿势较低，上半身没有摆臂和前倾；步态摆动与接触的速度衔接也需改善。当前尚不能作为合格的正式跑步动画。实验、候选素材及录像未接入正式游戏。

轮廓修正：添加 running_layer_capture.gd，用独立颜色显示各层。确认后腿的向下长尖角来自被归入小腿的裤脚边缘，修改 source_group 的局部裤脚边界，将其留在大腿层。重新渲染后长尖角消失。也加入 alpha 最大连通区域筛选，避免候选图中孤立像素进入动画网格；筛选仅作用于渲染几何，原图不改写。

修正后再次运行 running_gait_audit：支撑高度误差仍为 0，世界水平单帧漂移约 0.0000011，翻转三角形 0。整体姿势仍偏蹲、上半身静止，未达到正式替换要求。

重心与前倾：支撑时保留下压高度，腾空时将躯干抬得更高，脚掌前摆抬高量由 24 降到 18，减少蜷缩。躯干绕髋部中心前倾 0.1 弧度，原脸与衣领整体旋转，不独立变形。裤腿的径向旋转改为使用相对躯干的角度，避免重复叠加前倾。实际 running-bend.png 检查及审计重跑通过，支撑误差和三角形翻转数保持上述结果。尚缺摆臂、武器握姿随动、动作衔接与游戏内整体验证。

摆臂阶段：原图前臂与剑归入同一绘制层，另一手臂独立一层，围绕袖口反向摆动，幅度 0.24 弧度。剑与握手使用同一刚性变换，不再与躯干固定。候选下半身的右手残片原先混入裤腰区域，收紧该处取样边界后移除。检查 running-bend.png 和 running-frames/0006.png，手部无重复，剑跟随手臂；脚底审计仍保持上述结果。

当前仅有袖口以下的整体摆动，肘部尚未独立屈伸。仍需更自然的持剑跑姿、起跑停止、跳落及连斩衔接；此试验尚未替换正式角色。

进一步将袖口至肘部与肘部至手部拆开，前臂继承上臂旋转，再施加随步态变化的少量屈肘。剑仍与持剑手共用前臂变换。肘部底色覆盖仅用于小幅接缝。实际截图未见手剑脱离；120 帧双肘连接最大误差约 0.0000216 原图像素，支撑误差和网格翻转检查仍保持上述结果。录像已更新。屈肘目前幅度较小，尚无起停、跳落、连斩衔接，不作为正式动画交付。

起停样片 hero_transition_capture.gd：0.3–0.65 秒逐步起跑，2.0–2.35 秒退出跑步，前倾、步幅与摆臂统一受 motion_amount 控制。初版在零移动时仍进行了膝关节逆解，使静止腿部反弯；改为将关节角从原始绑定姿势逐步带入，零移动时恢复原角度。截图 transition-frames/0000.png 已检查。该过渡目前不锁定落脚世界位置，不能声称起停无滑步；需继续校准接触与移动距离。输出 builds/qa/locomotion-transition.mp4，未接入正式游戏。

地面约束实验 contact_enabled：在支撑开始记录世界横坐标，身体移动后反算局部落脚位置，用两段等长关节求解保持脚掌位置；选取接近当前膝盖的解，避免直接翻转。摆动时释放锁定，目标超出腿长则释放而不拉伸。contact_transition_audit.gd 在 3 秒起停序列中得到 328 个锁定采样，最大世界位置误差约 0.0000011，关节误差约 0.0000381 原图像素，但发生一次不可达释放。不能据此声称完整起停无滑步，后续需定位释放时间并处理迈步。

hero_contact_capture.gd 生成 builds/qa/contact-transition.mp4，开始前清空支撑状态与累计位移。角色保持画面中固定位置，通过累计世界距离核算脚底；当前预览尚未画出滚动地面，因此视频不能单独证明世界锁脚效果。

进一步处理起跑 .4667 秒处的不可达目标：根据已锁定脚掌的水平距离与真实腿长，计算必要的小幅骨盆下沉，上限 6 原图像素；整套躯干与关节一起平移，再求落脚解，不延长骨骼。30/60/120 更新率分别检查，均无不可达释放，锁定世界误差小于 .000002，关节误差小于 .00004。最大下沉分别为 4.0617、2.0166、1.0899 原图像素，说明接触采样仍有帧率差异，尚不能声称三种帧率视觉完全一致。

录像现已加入与累计世界位移同步的滚动地面刻线，并检查 contact-frames/0028.png 的起跑落脚。该阶段完成的是指定起停轨迹的可达约束修正，尚未验证其他速度曲线、转向、斜坡及跳落；正式角色未替换。

固定采样：新增 tests/locomotion_timeline.gd，以 120 Hz 推进指定起停序列，位移使用相邻速度的梯形积分；绘制读取 sampled_pose，不再修改接触状态。contact_transition_audit 先记录 120 Hz 的全部关节变换，再比较 60、30 Hz 对应时刻，角度与位置差异均为 0。三种采样的不可达释放均为 0，最大骨盆修正均为 0.223223 原图像素。这证明该测试轨迹的状态不再依赖绘制频率；不代表现有游戏已采用此驱动，也不代表任意输入或超过 120 FPS 的插值已验证。录像更新使用此固定采样驱动。

## 站姿基准线校准

最新修改将替换腿部几何按左右脚各自可见底边校准到原人物 y=199，保持腰部 y=143；关节位置采用同样的纵向映射，原头部、脸部、衣领与上衣纹理不变。此前腿部素材偏高，贴地求解会把静止腿部压弯，导致收剑后膝部出现额外折角。

新落脚也参与骨盆可达性预检查，避免减速末尾一只脚刚进入支撑时丢失约束。求解长度余量从 .1 调为 .001 源像素，避免把原图接近伸直的腿强制压弯。接触点保持求解，未用拉伸腿部补偿。

验证：起停 30/60/120 采样检查均无脚底释放、同一时间点姿态一致，最大世界脚底误差约 .0000011；完整跑步无翻折三角形，腾空样本 76/120。实际输入实验场跳台、三段命中、方向翻转通过。仍属于新二维动作实验，正式三关尚未切换。
