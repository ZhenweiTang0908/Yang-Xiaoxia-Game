# 界面减负

目标：战斗期间只保留资源、必要入口和真实台词；将操作反馈交给声音、状态区闪烁和原有动作特效。

- 标题页突出继续旅途，挑战集中在小区域，其余入口置底。
- 设置按声音、旅途分栏，保留骨骼动画与经典 2D 切换。
- 移除战斗中央的技能名称、躲避说明、阶段说明、闪避奖励与常规失败提示；重要收集/出口仅短暂显示一句。
- 真实对白移至底部。暂停、死亡和结算不再绘制战斗 HUD。
- 新旅途确认保留明确覆盖后果、安全默认选项，删除逐项存档说明。
- 选关、武学、记录、剧情页面删去重复教程；武学效果仍保留供选择。
- 四类短音效区分焦点、确认、返回、失败。月露无法使用时状态区闪烁。
- 连续近处同色伤害数字合并，总数上限 6；不改变伤害结算。
