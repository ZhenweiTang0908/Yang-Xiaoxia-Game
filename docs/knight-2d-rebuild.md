# 断誓枪骑：原技术栈重制

根据用户最新指示，本轮使用旧 BOSS 的手绘 PNG 关键帧 + `actor_pose_art.gd` 二维网格过渡，撤下本轮试做的 Blender 模型、SubViewport、3D 材质及依赖。主角与原三位 BOSS 不变。

## 视觉草案
对照 `builds/qa/boss-clean-sheet.png` 的细暗轮廓、少量层次的手绘阴影、低饱和暗红布料和炭黑暗部。骑士采用旧银分片板甲、封闭面甲、暗红短披风与战袍，体型约主角两倍；战马为深棕色，黑鬃黑尾，皮革马具与暗红马衣。透明 PNG 共36个独立姿态，没有光滑3D反光和圆柱关节。

## 动作与出招
步战包含持枪待机、明显抬手、肩后回枪、低位枪气、普通刺枪、拉弓/松弦、握剑/高举/落剑、架枪，以及走动、拖锋、下马腾空、落地缓冲和败北。骑乘包含压枪、四拍奔跑、勒马、抬前蹄、蓄后踢/蹬出、枪柄抬起/下压。换帧采用现有网格过渡，释放姿态按命中帧立即显示，收招继续保留跟随动作，避免伤害出现时武器还没有出手。

保持已确定的机制：先马战，半血以下回满血下马；尘气固定10血和10秒封葫芦；弓箭/拖锋重斩有效命中封7秒；全场低位三枪匀速1.10秒，慢第三枪间隔2.05秒，依靠抬手而非危险区提示。

## 音效和特效
制作33个短促物理音效，马蹄、板甲、枪尖、弓弦、轻剑、重剑区分。马蹄按跑姿周期触发；10种实际命中声由攻击事件携带，不在挥空时播放。保留暂停/音量/音乐压低机制与预留音频声部。枪气只在释放时出现地面细带，剑招使用贴图武器端点产生短轨迹，拖锋与落地有少量火星和尘土。

## 交付和检查
36个独立透明关键帧、3张原始手绘图集、生成提示词记录、Godot 2D动画代码、最新macOS/Web产物。检查姿态切换时的脚底、武器端点、左右朝向、下马和战马离场，并回归骑士阶段与封葫芦测试、旧三关和参数面板。
