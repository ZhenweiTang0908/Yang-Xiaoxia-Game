# 衔灯狮叟实施计划

依据：用户已确认 docs/lion-elder-design.md 的完整战斗设计并明确要求继续实现。本文只分解已批准范围，不增加批准流程。实施同时采用 engineering-quality 与 godot-headless-test。

|合同要求|实现任务|验证|
|---|---|---|
|R1 第五战路线、旧存档、结算和场景|T1 连接第五战，保留前三奖励及枪骑重试|lion_route与旧路线测试|
|R2 20招、承诺判定、两阶段和破势|T2 独立actor与可调catalogue，F2，主角现有能力|逐招判定、清理、左右和反制测试|
|R3 简洁画风与272独立姿态预算、更多过渡|T3 图集、锚点、逐招姿态时间轴与补画|原尺寸真实截图、左右／半速动作视频、逐帧审看|
|R4 全动作声音、68台词、哥哥优先|T4 Foley、录音、路由和事件|WAV合法性／来源、实际事件音频和试听|
|R5 可玩性与公平性|T5 集成回归与手动攻防场景|无无敌辅助的无伤解法、难度模式和墙角|

T1、T3工具、T4素材可独立进行；T2先保证所有招式契约，再与T3/T4接合；T5以真实运行证据验收，单纯绿灯不能替代画面与操作。每项未满足保持未完成。不打包、不部署。
