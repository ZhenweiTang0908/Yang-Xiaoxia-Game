# 渡口木构与渡船

第二关的薄实体高台改为木质梁面，与单向木栈道使用一致的低饱和材质。木结构每跨保留一根斜撑，替代原双斜撑交叉；单向平台增加桩头接缝与单斜撑，水上桩脚延伸到水面下，并用更暗色表示浸水部分。上述支撑都是背景装饰，不增加碰撞或改变可走范围；明亮边缘只保留在原平台顶面。

第一、二关的渡船外形改为八点收拢船身、稀疏舷线和较暗水线，减少原梯形块观感；甲板宽度、高度和运行轨迹不变。第三关的浮台仍采用原石质造型。

原生 dock_visual 在第二关 x=2670 木高台、5150 渡船、6330 升降台附近捕获画面；截图位于 builds/qa/dock-2670.png、dock-5150.png、dock-6330.png。程序正常退出。此为纯绘制修改，没有修改关卡配置或物理节点，因此本轮采用视觉检查，没有重复整套战斗测试。

整体三关平台布局仍相似，当前只推进材质和结构辨识度，并不代表关卡设计与全部场景美术目标完成。Chrome 本轮未实机验证。
