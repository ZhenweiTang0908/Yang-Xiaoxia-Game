# 跑步原画候选审查

本轮使用内置 imagegen，参考 assets/art/hero_2d/hero/00.png。候选在 art_source/run-studies/candidate-01.png，仅用于审查，未接入游戏。

提示词：保持参考的脸、头身比、短黑发、自然短颈、橙袖米白小熊上衣、黑短裤和赤脚；4×2 八帧右向完整跑步周期，接触、下压、经过、腾起及另一腿对应四帧；固定肢体长度，单把短剑，透明背景，等大格子和充分间距，不新增装饰、文字、阴影或拖尾，不做三维渲染。

审查结果：不采用。生成图变成较粗的插画轮廓；两行未充分区分左右腿的交替；背景棋盘被画入 RGB 图像，不是真实 alpha。不能直接导入，也不能把生成八张姿势当作连续动画完成。

同步进行的 tests/hero_stride_experiment.gd 将周期缩至 0.24 秒，在 225 像素/秒下以 27 像素后蹬锁定支撑脚。锚点漂移为零，但 0070 截图显示小腿被明显拉长，视觉审查失败。该实验没有接入正式角色。

下一步所需资产是保持现有上半身的局部腿部姿势和可控制的膝关节连接，而不是继续靠全身网格把脚硬拉至目标点。正式角色、导出包保持上一轮版本。
