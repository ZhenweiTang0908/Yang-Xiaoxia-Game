# 原画分层实验

之前在共用网格上做固定腿长，双腿交错会折叠贴图。新实验 tests/hero_layer_study.gd 使用原有 10.png，按像素网格归属分为躯干、左右大腿和小腿五个独立绘制层。原始 PNG 未改写，静止时可还原原画；头脸、上衣、手和武器留在同一躯干层。

初次检查发现脚尖误归躯干、小腿缺少父骨骼变换。已修正分类边界并让小腿继承大腿旋转，局部关节留有覆盖。查看 layers-rest.png、layers-bend.png，脚尖不再脱离，脸与衣服保留。

进一步将双脚独立为第六、七层，脚踝位置继承小腿，脚掌反向抵消父骨骼角度。后脚保留原画腾空时的脚掌方向，不能据此声称实现平脚着地。补上后膝和后踝的遮缝底色，头脸和上衣仍为完整原画。

合并同一行中属于同一层的连续像素，9744 个逐像素四边形降为 324 条纹理条带，减少约 96.7% 几何量；纹理坐标与覆盖面积不变。layer_rest_validation.gd 检查面积为 9744，静止截图与左侧原图逐像素比较差异为 0。foot_layer_alignment.gd 检查 240 次脚踝连接及脚掌世界角度，错误为 0。样片已重新录制为 builds/qa/leg-layers.mp4。

这仍是分层和屈伸样片，不是完成的跑步循环。尚需合理的遮挡层次、地面约束与跨姿势衔接；不得接入正式游戏或声称滑步已解决。实验位于 tests，不随游戏导出。本轮未修改正式角色或重新发布客户端。
