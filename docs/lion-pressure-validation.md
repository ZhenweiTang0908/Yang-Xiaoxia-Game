# 第五战强度修订与验证（2026-10-26）

本轮沿用用户要求继续优化的授权，在现有未提交实现上修改。未提交、未打包、未部署；已有锚点、美术、台词和五种休整均保留。

## 实际改变

1. 正常换招不再清掉已经吐出的弹丸。破势、转阶段、Boss败北和玩家死亡仍清场。
2. 狮口仅叼正面玩家普通箭，容量默认2、F2上限3；满嘴、出手/收招、休整、赶场中可以被箭打中。火焰、剑气、哥哥飞牌不走接箭。口中增加可见箭杆。
3. 醉闪有独立3秒间隔，并受远招冷却限制；赶场及收势中不可闪箭。
4. 一阶段吐完后，远处玩家会引来赶场。两阶段赶场均在起手锁定方向与终点，0.45秒预兆，460px/s，最多1.8秒，终点离起手目标20px，基础伤害24×1.5=36，收势0.7秒。跳过、换边、翻滚和收势射箭均有出口；不会在奔跑中跟随目标改向。
5. 远处追赶245px/s，主角普通跑速225px/s；远处判定180px。原二十招保留前摇与1.5伤害倍率。
6. 选招额外检查招式行程与各段范围，不再仅靠宽松的选招半径；背踢只在身后有目标时选择。没有可及招式时靠近，补掉30–100px的停步空档。敌人不会在起手后取消招式来追逐逃跑者。
7. 赶场与吐回使用已有音效素材配齐预备、蓄势、出手、落地与收势；赶场实际命中才播撞击。保留前次实现的招名辅助。
8. 直接切换姿态时同步镜像，避免自动截图在手动换朝向后仍显示上一姿态的镜像。原图均朝左，未更改其原始方向。

关键文件：`scripts/actors/lion_elder.gd`、`scripts/core/balance.gd`、`scripts/animation/lion_elder_visual.gd`、`tests/lion_ranged.gd`、`tests/lion_fairness.gd`、`tests/lion_capture.gd`。仓库中的这些新Boss文件本来尚未跟踪，不能只靠 git diff 判断本轮范围。

## 验证

所有 Godot 运行使用项目包装器，图形验证使用后台、Dummy音频、真实渲染及实际PID超时清理。

- `lion_ranged`：61项。容量、穿透机会、醉闪冷却、换招保留弹丸、破势清理、两阶段两朝向撞肩伤害及唯一性、预备无伤、固定终点、换边/跳跃躲避、收势射箭、姿态镜像，以及移动射击压力。
- `lion_fairness`：2992项。选招、二十招可达、左右判定/时序、每段唯一结算、暂停/命中停顿、中断清理、原画接触与F2时序。原测试假定所有距离都必须有招式，现在允许在不可及距离走近；测普通招式时隔离远招冷却，反远程另由上项验证。
- `lion_combat`：155项；`lion_counterplay`：12项；`lion_tuning`：369项；`lion_audio`：678项；`lion_art`：866项；`lion_dialogue`：104项；`lion_route`：19项；`lion_import_ready`：1087项，353帧导入可用。
- `lion_fight_sim`：种子7、88均通过，阶段变化、休整、整战结束与胜利流程正常。此模拟会维持主角生命且缓慢给Boss固定伤害，只证明整战流程，不证明难度平衡。
