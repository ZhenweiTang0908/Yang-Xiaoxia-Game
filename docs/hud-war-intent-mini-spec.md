# HUD 与战意 Mini Spec

## Goal
提升血瓶、主角资源条与 Boss 血条的精细程度，保持当前简洁的武侠配色和战斗可读性。

## Expected Behavior
- 主角状态框左侧显示“血量”和当前/最大生命，下方显示“战意”和当前值；战意条中显示伤害倍率。
- 战意伤害倍率为 1 + 0.25 × clamp(战意 / 100, 0, 1)，0/50/100 分别为 1/1.125/1.25。对主角及羊灵的近战、指令技、箭矢、剑气、蓄力与角击一致生效；飞行攻击在发射时锁定倍率，单次攻击多个目标用同一倍率。
- 成功启动“冲刺”扣当前战意的 10%，翻滚不扣；冷却、骑乘、形态切换等条件阻止冲刺时不扣。
- 移除蓄力原有的额外固定战意加伤，统一按上述倍率；保留蓄力释放清空战意、自然衰减、击中/击杀/完美闪避等战意来源。
- 瓶身有轮廓、瓶塞、液体与反光；空瓶仍可辨认。资源条有暗槽、金属描边和细微高光；血条有受伤缓降，Boss 保留受伤缓降并显示生命数字。
- 保持移动端安全区与原有点击操作；数值、标签不得与血瓶、召唤状态或 Boss 战怒格重叠。

## Constraints / Out of Scope
保留血瓶恢复量/次数、敌人生命及攻击数值、牛大侠规则、原有操作映射。使用 Godot 原生绘制，不引入新图像依赖。

## Open Questions
None。将“气条”按用户紧接着定义的“战意”呈现。

## Verification Target
检验各攻击 0/50/100 战意倍率、弹道飞行期间倍率不变、冲刺与翻滚及失败触发的扣除规则；截图检查桌面、移动端、低血/满战意、Boss 受伤与空瓶。
