# Mini Spec: 羊小侠方向搓招

## Goal

为人形羊小侠增加三个方向搓招，键盘与手柄使用同一识别规则。

## Expected Behavior

- ↓前 + 攻击：踏月剑气，向前发出穿透剑气；↓后 + 攻击：回风斩，攻击两侧；前↓前 + 攻击：升龙斩，向上跃起并斩击前上方。
- 方向在 0.75 秒内完成，最后方向后 0.3 秒内按攻击；允许斜方向过渡，按起手朝向镜像。三段搓招优先于两段。
- 三招共用 1 秒冷却，不消耗觉醒或战意。普攻命中后可取消后摇接搓招；普攻出手前输入则短暂缓冲。
- 有独立攻击范围、特效及招式名反馈；操作说明列出三招。未满足条件时仍执行普通攻击。

## Constraints / Out of Scope

- 保留 J 三连斩、弓箭、蓄力、闪避及手柄短按/长按行为。羊灵形态、骑乘和变身过渡不发动新招。
- 暂停、受伤、重置、变身和骑乘清空搓招输入，避免跨状态误触。

## Open Questions

None.

## Verification Target

- 三招在两种朝向下均能识别，超时、长按方向、单方向和错误顺序不触发；升龙斩优先。
- 命中时才产生伤害/剑气，未激活 Boss 不受伤；冷却和取消规则有效，原三连斩及手柄行为通过回归。
