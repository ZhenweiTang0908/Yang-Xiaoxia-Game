# Mini Spec: 受击反馈与敌人招式音效

## Goal

让受击瞬间可见、可辨；按敌人与招式区分蓄势、出手和真正命中的声音。

## Expected Behavior

- 覆盖 8 类普通敌人及三个 Boss 的全部 20 个招式，共 28 套声音身份。使用已有 CC0 录音素材制作爪击、重砸、扑咬、振翅、飞镖、盾击、刀刃、灵火、符印、落雷、灵束、刃雨、裂隙和大阵等声音。
- 弹丸和延迟区域在生成时保存声音身份，飞行期间切招、换阶段也不串音。
- 实际扣血才播放受击音效并显示受击冲击；无敌、骑乘保护、闪避不误播。延迟攻击落地有对应攻击声，群体区域进行限频，避免同帧叠加。
- 玩家、敌人与 Boss 获得更清晰的短闪色和冲击标记，玩家受击有短停顿、轻微边缘提示；敌人短暂视觉后仰，不取消攻击预警。
- 受击声音使用独立声部，并短暂压低背景音乐，保持静音与原音量设置生效。

## Constraints / Out of Scope

- 不改变伤害、碰撞范围、无敌时间、连招输入与敌人招式规律。
- 保留既有普通近战按材质区分的命中音效；不使用全屏强闪。

## Open Questions

None.

## Verification Target

- 28 套声音均有合法、不同的 warning/release/impact 音频；检查峰值、时长和来源。
- 实际攻击路径传递正确身份，延迟攻击身份稳定；命中与无敌分支反馈正确，声音池拥挤时受击仍可播放。
- 回归近战、搓招、受击预警、阶段切换和完美闪避；检查受击截图与试听文件，重新导出 Mac/Web。
