# 石波与碎石起落

stone_motion 根据攻击区域宽度生成 2–5 块石头。44 像素短石波使用 2 块，96 像素落地冲击使用 4 块，减少原来每段固定五块的重复密度。石块大小与旋转方向略有差异，用抛物线起落代替同相位正弦上下移动；末尾略微缩小，底边不会穿过地面，配两团低透明度尘土。采用统一灰绿色与一条淡色受光边。

原生 lantern_visual 检查第一关实际石波，正常退出；stone_motion_visual 检查两种宽度在 .02/.15/.29 秒的六个形态，截图 builds/qa/stone-motion-phases.png。此项修改只涉及绘制，没有调整危险区、伤害、预兆和 Boss 招式数量。
