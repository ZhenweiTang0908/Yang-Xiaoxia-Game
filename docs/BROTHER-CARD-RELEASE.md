# 牛大侠出牌同步

修正了投射物先生成、伸手帧后更新的顺序。达到释放时刻时，先固定面向目标并同步到出牌帧 14（牌阵沿用帧 20），更新对应网格基准，再执行出牌。出牌仍保留 .14 秒准备和原 .42 秒动画总长，不改变技能伤害与冷却。

brother_visual.mesh_socket 从包含手部坐标的实际网格三角形采样，使用三个顶点各自的蒙皮权重，再插值得到手部位置。此前统一按腰骨权重估计手的位置，可能与画面不一致。原牛大侠纹理、脸型、发色、服装和脚底处理保持原样。

brother_skin 原图与有界形变/固定脚底检查通过。brother_card_release 在实际召唤实例中检查左右两向，共 10 项通过：准备期间不产生投射物、释放帧与网格帧一致、起点位于变形手部、飞向目标、手部位于网格内部。原生执行同样通过，并捕获 builds/qa/brother-release-left.png 与 brother-release-right.png。

本轮修复释放同步，不代表哥哥所有姿势之间的连续性都已重做。Mac、Web 更新导出，Chrome 本轮仍未实机验证。
