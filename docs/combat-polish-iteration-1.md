# Mini Spec: 动作与战斗反馈继续打磨

## Goal

让三套搓招拥有可区分的身体动作与轨迹，明确区分命中、格挡、挥空。

## Expected Behavior

- 踏月剑气前推动作与青色出手光；回风斩环身挥剑与双向旋刃；升龙斩上挑与向上延伸的金色剑弧。
- 搓招特效在原有伤害事件时产生，短暂淡出；支持左右镜像、暂停/停顿冻结、数量上限和切关清理。
- 普攻命中火星在人物前景显示；肉身、石甲、Boss、盾牌材质各有清晰但短促的视觉反馈。
- 格挡使用盾弧与反弹火星，避免显示普通肉身受击十字；挥空不产生命中火星与震动。
- 命中震动按轻斩/终结斩区分，遵守已有关闭震动设置。

## Constraints / Out of Scope

保留伤害、判定范围、招式时刻、冷却、搓招输入、敌人预警与已有参数面板。

## Open Questions

None.

## Verification Target

检查三招左右镜像与前景材质反馈截图，回归关节连接、剑光对齐、命中/挥空/格挡、暂停/数量上限、搓招及参数面板，重新导出 Mac/Web。
