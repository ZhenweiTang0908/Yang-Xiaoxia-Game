# 守石兽重做设计（已确认并实现）

关联验收规范：[boss-reset-spec.md](boss-reset-spec.md)，主要需求R01/R02/R06/R07/R14。

## 人物与支柱

它是一头与石庭连在一起的山门石兽。核心动词是“掀”：脚掌压地，石头便被它掀起、推走、投出；近身则用石质肩背和角冠驱赶侵入者。

保留四足、角冠和沉稳轮廓；灰石替代毛皮的主视觉，肩背像几块完整石板相扣，关节有转动余地。胸前撤灯坠，改为小块圆石扣。只保留必要的大块石缝，不能做成满身裂纹、符文或碎石噪点。半血阶段叫“山石共鸣”，石块响应更紧凑，身体仍是同一头石兽。

- 石头来自地面：尘土松动→碎石浮起→兽体发力→岩块运动。
- 身体有重量：脚先压稳，肩再走，角最后跟随；不能整体平移一张图。
- 控地与近身轮流出现，不持续封地；正确绕背可利用它75%不回身的连段。

## 与主角系统的关系

普通三连斩打身体收势；踏月剑气可趁它掀石打硬直窗口；升龙斩/蓄爆命中飞出的可击碎岩块时给碎裂、失衡和低沉回应，不能只有特效无结果。羊灵跳跃/角冲能越开滚石但不能无视岩浪；牛大侠仍能靠实际冲撞命中躯干，石兽不会瞬间转向去追牛。月露可在长扑后的收招中使用。

## 灵感来源与取舍

本轮跨动作游戏、MOBA、电影、神话文字和真实兵器研究，完整出处与四栏记录见总规范末尾“调研来源”。本角色具体借用岩雀“岩块来自地面且有实体运动”的材质因果，以及《师父》动作前后重心都要可信的原则；不复制岩雀整套技能或地雷规则。电影《侠女》的静与突然发力用于扑进节拍；神话石材意象只提供“山庭有主”的身份感，不加入五色石或新神祇设定。
