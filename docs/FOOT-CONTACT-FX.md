# 支撑脚与地面效果对齐

二维跑步触发脚步效果时，使用当前较低脚的世界坐标。地面效果再向附近碰撞面投射短射线：只有脚下确有朝上的地面才产生尘土或水纹，最终位置贴合该表面。不存在地面时不生成效果。

修正尘土边界检查，最多 18 个，不再允许末次插入超过上限。ground_presence 九项检查通过，覆盖浅水、干地、高台、空中、暂停、阴影衰减与数量限制。

此次只对齐脚步效果，不代表解决世界空间的脚掌滑动。跑步音效的原有节奏不变。

## 动作驱动落脚（2026-09-14）

脚步声和扬尘不再使用固定半周期时钟，改为当前二维姿势支撑脚切换时触发。高度差 0.25 像素的滞回避免双脚接近同高时抖动；离地、待机或形态隐藏清空记录。三种脚步声独立轮换，不因脚标识固定为两个音效。

tests/foot_contact_timing.gd 对实际主角姿势逐帧采样：30/60/120 FPS 三秒均 11 次支撑变化；每次触发的脚锚点位于地面，离地/待机不保留支撑。它验证事件时序，不证明像素脚掌无滑动。现有原画步幅问题仍然存在。
