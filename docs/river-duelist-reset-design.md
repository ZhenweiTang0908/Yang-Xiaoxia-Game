# 河边剑士重做设计（已确认并实现）

关联：[boss-reset-spec.md](boss-reset-spec.md)，主要需求R03/R06/R07/R14。显示名暂沿用“渡影刀客”，不擅自改动用户未指定的专名；视觉与打法明确为剑士。

## 人物与支柱

他在河岸断桥拦路，是一个靠步法、剑尖和飞镖控制距离的武人。核心动词是“穿”：先以镖逼出走位，再以承诺方向的直线突刺穿过空隙。

沿用暗红纯色衣、面具和清楚的飘带轮廓；右手主兵器重画成长剑，左手暗器是小型实体飞镖，不能把飞镖也画成长剑气。脚步有蹬地、前掌承接与后脚回收，河边少量水雾只作脚步反馈，不凭空变成水法师。

- 主威胁是直刺和短促连续踏进，出剑后不追着玩家转弯。
- 镖是有手腕发射动作的实体，不是无来源扇形光线。
- 多样化保持原强度：2600生命、12–30单段伤害级别、0.65–0.9s主要起手和约0.8s以上收势。

## 八招与初始数值

时间从起手计。突刺相关招式合计约65%选招权重，其余为独立飞镖和跃步，按距离筛选后归一化；新组合替换旧权重，不能在原七招后额外塞入攻击造成密度上升。

## 平衡对照

重做前先按现有77项战意验证对应的新主角规则记录基线，不能拿未加战意时的玩家伤害作对照。保持同种难度、武学、牛大侠和玩家策略，记录固定种子战斗的伤害、攻击密度、通关时间和失败比例。设计验收目标为中位通关耗时变化≤15%、固定策略死亡率变化≤10个百分点；不足时调节权重与可反击空隙，不削弱羊小侠或增加隐形预兆。

## 灵感来源

完整跨媒介调研见总规范末尾。FIE技术规则的剑尖先威胁、后脚推动与前足承接用于D1；《侠女》竹林交锋的停顿与突然穿行用于D8，不能借剪辑省掉游戏中必须存在的中间动作；《师父》可信重心与发力/收势用于每段脚步；MOBA研究只借“移动与释放分属可见拍子”的一般原则，不移植岩石、法术或现成英雄整套技能。

## 验证

刺击始终从手中长剑发出；D1/D7经过的路径只在剑尖到达时危险；飞镖真实离手、旋转、返程及命中都一致；25%段间转身、墙边穿身后挥空、8招选中、原强度对照和108张实际姿态均须通过，不能以整体数值削弱掩盖动作不公平。
