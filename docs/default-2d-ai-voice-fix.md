# 默认2D与AI配音修复约定

2026-10-27 用户在部署上传阶段要求暂停，并明确默认2D动画、默认AI配音，修复经典切AI听不出变化。

## 已确认事实与原因

- 新存档原来 `hero_mesh=true`，旧存档还会迁移到新版骨骼，不符合当前默认2D要求。
- 配音设置按钮本身会更新 `boss_voice` 并试听骑士AI音频；前三位重做的181个启用台词ID均没有对应AI文件。
- `audio_director.voice_path()` 在AI文件缺少时回退经典录音，所以战斗中仍然是经典声音。
- 本机已有 tutorial-video-generator 的语音服务配置，已验证必需配置存在，仅供进程内生成使用，不复制密钥到项目。
- 部署已中止，服务器current仍为 `releases/20261026T142538Z`；`20261027T091357Z`是未启用的中断上传目录，已在校验非current后清理，避免被后续回滚误选。

另发现旁支问题：原先所有非playing场景都会暂停对白，包括归月剧情；现将剧情语音视为可播放，暂停菜单仍冻结，避免同伴台词暂停后导致归月等待不结束。

## 修复后行为

1. 新存档和未完成本次迁移的旧存档默认经典2D、AI配音。
2. 迁移仅一次；之后主动选择骨骼/经典配音依然保存，不因重启或开始新旅途被覆盖。
3. 前三位重做181句补齐真实AI WAV，保留经典版本；AI选择必须解析到新AI资源。
4. 从经典切AI、再切回经典时，实际播放源、选中状态、保存结果一致，试听不被设置界面暂停。
5. 旧存档进度、音乐/音效、牛大侠原有录音与其他战斗规则保持原行为。
6. 改动完成后验证源码及实际导出包中的AI资源，不自动恢复已暂停部署。

回归覆盖新默认、旧存档一次迁移、用户后续选择、设置双向切换、启用台词全量覆盖、资源包路径。

## 完成证据

181句重制台词均由 `gemini-3.8-flash-lite-tts` 生成，未使用备用模型；SHA256、时长、非静音和削波检查全部通过，脱敏来源并入 `data/voice/ai_manifest.json`。经典版本仍独立保留。`default_2d_ai_voice.gd` 13项和 `save_store.gd` 11项回归通过。
