# 跑跳衔接样片

tests/jump_timeline.gd 按 120 Hz 固定采样生成跑动、跳起、落地、恢复跑动序列。使用当前 player.gd 的 520 起跳速度与 1080 重力，匀速前进 225。空中清除 planted 锁脚，收腿并增加屈肘；接近地面时收腿量逐渐退出，落地后用 0.16 秒接回跑步相位，避免立刻换腿。

tests/jump_transition_audit.gd：313 次采样，最高点 125.18333 游戏像素，与解析抛物线相符；空中没有残留锁脚，关节连接误差最大约 0.000049 原图像素，无不可达释放。该测试采用预定抛物线，不经过 CharacterBody2D 碰撞，不证明实际平台跳落、可变跳高或受击中断正确。

tests/hero_jump_capture.gd 输出 builds/qa/jump-frames 及 jump-transition.mp4。查看最高点附近 0060.png；保持原脸和上衣，空中姿势仍需美术打磨。落地冲击的身体缓冲、尘土与音效尚未接入此实验；正式游戏角色未替换，也没有重导出客户端。
