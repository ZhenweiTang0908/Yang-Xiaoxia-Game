# 正式二维人物动作接入

羊小侠的待机、跑步、起跳、下落、落地和三连斩已接入正式 hero_visual；使用原头部、衣领和上衣纹理以及校准过脚底的分层腿部。弓箭、蓄力、翻滚、受击继续使用现有二维动作；羊灵、骑牛仍使用各自资源。支持状态只显示新 rig，其他状态只显示对应旧动作，避免两套人物叠画。

代码位于 scripts/animation/painted_rig；tests 下的三个旧入口改为继承正式代码，样片与游戏共用实现。游戏从 assets/animation/painted_rig/hero.res 加载 11 个预建网格，不在启动时扫描原始图片。每个角色独立持有两片可变形短裤网格，其他静态网格可共享。若修改分层或关节坐标，用 Godot --headless --path . --script tests/bake_painted_rig.gd 重建缓存，再检查样片。不要直接改缓存数据代替源代码。

player_motion 在固定物理更新中读取现有玩家状态，接入起停、方向翻转、脚底约束、跳跃解锁、落地重心和上身过渡；沿用正式音频和地面接触反馈。暂停与命中停顿冻结该模块。

- interactive_lab_audit：同一正式代码跳台成功、三段命中、翻转通过。
- upper_body_transition_audit：9 次关节过渡最大误差约 .000025 源像素。
- movement：旧测试引用了已删除的早期平台；改为当前配置的 x=2340 低台、x=2380 屋顶和 x=2880 上层平台，实际跳跃三项通过，实体墙阻挡通过。三关可达性图检查通过，但不等于三关全流程人工通关。
