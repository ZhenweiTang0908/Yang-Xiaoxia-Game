# 投射物自然到期收尾

自然到期的卡牌、火焰和其他投射物保留 0.18 秒纯视觉收尾；不参与 shots 碰撞，最多 24 个。卡牌缩小淡出、火焰收束、箭刃保留短线。命中仍使用原有命中特效，避免重复爆闪。施法者清理和切关清空收尾，暂停冻结。

修复共享火焰内层插值颜色时把 alpha 拉向不透明的问题，内外层现在沿用调用方透明度。

验证：projectile_endings 检查到期不伤害、暂停、施法者清理、数量上限、超时和 clear；skill_lifecycle 26 项通过。projectile_endings_visual 在真实关卡中生成三种收尾并截图；无额外常驻光圈。退出时仍有已有资源泄漏警告。
