# 牛大侠与骑乘牛魔

本版替代早期六臂、牛人和三叉戟设计。羊小侠为弟弟；牛大侠普通形态是两臂人类，保留眼镜、嘴下痣、绿白齐肩发，以卡牌战斗。服装为简洁深色外套，没有牛角、牛腿和鳞片。牛魔形态是四足黑牛，羊小侠坐在牛背上。

## 战斗与保护

- 共用50生命。弟弟生命低于80，每次出牌5%概率变身；低于30为30%。每次召唤最多变身一次，额外助战30秒，下次召唤恢复人形。
- 变身后骑乘保护7秒，前5秒每秒恢复3生命。上背和下背使用平滑过渡，骑乘期间跟随牛背起伏；可攻击，但不能自行移动或闪避。
- 牛魔低头预备后向前冲撞，默认速度440、行程180像素。普通冲撞22伤害，蓄力闪现冲撞28伤害；单次最多命中3个敌人，同一目标不能重复命中。每次实际命中自愈1生命。
- 普通锁定0.75秒、蓄力锁定1.2秒，闪现至敌人背后再冲撞。闪现本身不造成伤害。目标死亡、落点在实体内或不可靠时取消；冲撞检查前方地面，避免直接冲下断崖。
- 已删除三叉戟、额外手臂和武器模式。人形仍使用原有四种卡牌技能。
- 出场约1.2秒，正常助战30秒；离场约0.8秒后开始100秒冷却。暂停冻结计时；死亡、切关和重试清理骑乘及召唤实例。
- 保留变身字幕和离线合成语音“唐牛牛在此，谁敢放肆！”。

## 调试

F2或右上角“调”打开调试窗口。29项参数包含变身概率、生命、骑乘和治疗时间、冲撞速度/行程/预备时间、伤害、命中人数及锁定冷却。应用后保存到user://balance_v1.json；既有自定义数值保留，可手动恢复默认。

测试脚本 tests/demon.gd 验证概率、计时、治疗、碰撞伤害、单次命中限制、闪现安全检查和清理；tests/demon_visual.gd生成实际游戏截图。新美术及完整生成提示词见 SIMPLE-BROTHER-ART.md。当前平衡数值仍需要游玩反馈调整。
