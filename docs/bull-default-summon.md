# 牛大侠直接以牛形登场

默认召唤冷却 20 秒。初始体力 200，活动时每秒消耗 3，受到攻击继续扣体力，命中永不回血；体力耗尽离场，不再有独立的 30 秒助战期限。同心升级继续提升伤害。

召唤第一帧就是四足牛形，直接创建牛的碰撞体、绘制与控制器，不创建人形或投牌控制器。登场结束直接开始助战与原有骑乘/治疗；登场使用独立合成牛叫 bull_moo，不播放唐牛牛台词和变身音。原录音资源保留。标题/剧情中的配图改为牛形，参数面板隐藏已停用的人形、概率和变身延时控制。

封印恢复始终是牛，保留生命与剩余时间，不重复上牛/治疗/延时；死亡、离场、重试及切关解除骑乘。三格飞鹰仍固定打主角 25 并重置完整冷却，现在默认是 20 秒。

旧的概率变身 API 保留无副作用兼容入口；实际概率流程和人形攻击代码已移除。原有以人形和概率为前提的历史测试不再作为当前玩法要求；mount_rescue_trigger 已改为牛形默认召唤的 42 项检查，骑乘与封印回归沿用 mount_rescue。
