# 骑士招式扩充 Mini Spec

## Goal
丰富当前断誓枪骑的马战和步战，使推进、反跳、追击、近身连段及弓剑节奏各有可读动作与应对方式。原有技能全部保留。

## Expected Behavior
|ID|招式|动作与命中时刻（秒）|默认伤害|应对／收招|
|---|---|---|---|---|
|advance|马战·三步逼阵|每步抬前蹄；0.60 / 1.10 / 1.60各向前踏进28px，只有前蹄附近局部判定|每踏16|退开或绕后；最后一踏后0.95秒破绽|
|uppercut|马战·回缰挑枪|前0.30秒退步54px，枪尖压低；0.70秒向前上方挑枪|22|保持地面或退开；只覆盖地面上48–168px，收招1.0秒|
|lunge|步战·贯甲进刺|压肩蹬地准备0.70秒，随后0.28秒前进154px，枪尖连续扫过路径但每个目标只结算一次|26|观察蹬地后翻滚穿过或退出刺击路径；收招1.0秒|
|kick_thrust|步战·蹬踢接刺|0.50秒近身踢击，随后明显收枪，1.35秒直刺；连段中不瞬间转向|踢10、刺20|退开踢击，侧换位置或翻滚躲刺；收招0.85秒|
|bow_double|步战·退步双矢|先后退63px；0.70和1.60秒各一箭，两次分别拉弦并在出箭前0.25秒锁定瞄向|每箭12|持续移动或分两次翻滚；收招0.9秒|
|cross_cut|步战·交叉双斩|0.55秒横斩，0.95秒举剑重新对向并固定方向，1.45秒返身斜斩|16、20|读两次挥臂、分两次躲避或撤离；收招1.0秒|

新招优先按距离与空中状态进入候选；在近6招未用过的有效候选中优先选择。长连段／三枪之间至少穿插一个其他技能。每一段有独立准备动作和释放音，不读取玩家按键临时变招。新弓箭有效命中仍封葫芦7秒；新踢、矛、双斩不额外封印。

## Constraints / Out of Scope
沿用现有手绘PNG关键帧和二维网格过渡，补12张同画风姿态及6组准备／释放／实际命中音效。保持两阶段血量、半血下马尘气、匀速/慢第三枪、恢复骑乘、跳下牛背和封葫芦规则。不增加小兵、魔法、地面危险提示或BOSS额外阶段。新增6个准备时长、6个伤害参数接入现有参数面板。

## Open Questions
None；按推荐值直接实现。

## Verification Target
验证所有新技能可被选中、前摇期间不造成伤害、命中范围/时刻与动作一致、枪尖移动不穿透漏判、每段只结算一次、反跳招不伤站地玩家、双箭各自锁定且仅有效命中封印、转阶段/死亡能取消所有新技能。检查左右朝向和实机截图，回归骑乘及原技能后重新编译macOS/Web。
