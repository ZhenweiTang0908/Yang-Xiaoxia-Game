# 技能辨识度与生命周期

预兆按攻击方向区分：横向喷吐/光束显示方向箭头，落雷/悬刃显示纵向轨迹，地面碎石显示裂口提示。预兆阶段不消耗有效持续时间。

火焰保留像素火舌原画，增加短起焰与少量上升火星；结束后余烬仅为视觉，不延长伤害。碎石按自身攻击时长完成升起和回落，结束后只留下少量石屑。余效上限 24，按施法者与切关清理。

悬刃雨由橙色长条改为有护手、刃脊的银灰刀刃，0.12 秒内落到地面。碰撞框跟随可见刀刃，不再整条纵向路径同时伤害。伤害值不变，同一把刀只命中一次。

卡牌保留明确的白绿牌形、简洁菱形牌面和短拖尾；命中留下三片小碎片，特殊命中效果上限 24。缚灵牌阵改为四张卡牌围成的小阵，上限 4。普通近战在挥出窗口沿二维网格里的握点与刀尖绘制短刀光。
