# 刀光与二维表面同步

hero_2d_skin 原先为武器挂点独立计算连续权重，而实际贴图使用网格顶点插值；两者在局部刚性和衣摆修正后并不一致。现改为在已绘制三角形上插值获取挂点，刀光与武器使用同一变形表面。

验证：tests/blade_surface.gd 对三段攻击共 3000 个三角形中心，与实际 Mesh 顶点结果比较，误差低于 0.001；现有主角 17 项检查通过。重新录制动作样片，检查了第一、第二、第三斩的释放截图。

范围：这修复挂点计算差异；原画刀尖标注仍是人工坐标，且关键姿势之间的刀刃朝向跳变仍存在。本项不证明整段挥剑已经完全连续，也不解决跑步滑动。

## 短弧刀光

连接相邻采样时改为插值刀刃角度和长度，仅绘制外侧 32% 的窄带；不再从握点向两次刀尖填充整块三角形。跨招、转身、握点跳跃超过 18 或转角超过 117 度时断开，避免根据不连续原画推断错误挥刀路径。弧线按约 8.6 度细分。

新增 blade_ribbon 检查：90 度挥动保持内外半径，跨招/转身/反向跳变不连接；主角 17 项检查通过。重新录制并查看第一斩和第三斩释放帧，第三斩原先的大三角形消失。断开异常连接不会补出缺失的人物姿势，仍需要原画动作修正。
