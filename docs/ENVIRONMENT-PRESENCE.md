# 场景层次与落地感

三关背景降低对比度，分别偏冷蓝、雾青、灰紫。地面主体与可站立边缘按关卡配色，装饰保持较低对比。纠正庭院误用断桥地标的问题。

角色接触阴影射线检测实际碰撞面，支持薄平台、移动渡台与升降台；跳跃时影子留在地面并变淡，骑乘时不额外画弟弟的浮空影子。落地和起跳使用两团低矮尘土；前两关两处浅水装饰产生短涟漪，第三关保持干燥石面。渡台船底与水面高度一致，并有稀疏尾波。全部新效果暂停时冻结，尘土和涟漪数量受限。

受击透明度由 0.3 改为 0.65，避免小角色几乎消失；镜头抖动幅度限制为 3.5 像素，并加快衰减。

验证：接触面、涟漪、干地尘土、暂停冻结、空中投影、祭坛干地 6 项通过；三关原生截图 builds/qa/presence-stage-1.png 至 presence-stage-3.png。此记录不表示整体美术目标已完成，技能与其他角色仍需继续逐项视觉复核。
