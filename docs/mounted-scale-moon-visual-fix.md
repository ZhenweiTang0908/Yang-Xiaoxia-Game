# 骑乘动作、Boss体量与月光特效修复约定

## 证据与原因

- 默认2D的player骑乘分支隐藏正常攻击图、固定显示rider单帧；羊灵的update_animation结果又被art.frame=19覆盖。已有骑乘动作检查只启用use_skeletal=true，漏掉默认模式。
- actor_pose_art在换原画时把上一幅整图网格插值到下一幅边界；兵器举高、披风张开时，整个身体被对应网格拉伸。重制Boss按整张sheet的总高度定单位；骑士不同原画库也使用各自固定比例，不能保证头盔和身体体量一致。
- 第三位普通投射物、追踪弹、碎光雨和贴地波都复用实心月牙图形，读起来像投放图标而非月光。

## 修复范围

1. 默认2D及可选骨骼模式中，骑牛的人形和羊灵均显示预备、出手、命中与收势；骨盆附着背部，腿不变成站姿，既有伤害与时机不改。
2. 使用可复核的解剖标记逐帧统一比例，兵器和披风不参与体量定义；去掉跨不同原画边界的全身拉伸。人物、头盔与马匹不因换招换库缩放，坐骑/下马本来的姿态高度变化仍保留。兵器判定和残影使用同一变换。
3. 祭主普通技能采用银紫光丝、光刃、聚光与薄雾，区分环射、追光、落光和地面波；不再使用飞行月牙/月球图标。保留原有巨大月盘形态、权杖造型、归月剧情、伤害/范围/预兆时间与转身概率。
4. 新回归必须覆盖默认2D骑乘两种形态与三连击，检查实际姿态/兵器运动、座位固定；检查Boss解剖尺度和不同关键帧之间的刚性，出真实渲染动作视频。
5. 不自动恢复之前已暂停的部署。

## 实现与复核（2026-10-27）

- 人形骑乘使用现有2D分层原画骨架，保留三连击上身曲线，骨盆固定牛背，双腿折起。默认2D原有伤害仍在0.12秒生效，显示时间映射到每招实际出手姿势，不改变伤害和连击时长。
- 羊灵骑乘新增独立2D上身渲染，使用原有4/5/6幅挥刀序列；象牙色连通区域定位头部，排除腰带和脚部亮点。坐姿下肢与上身分开，裁切保留整条绿色刀刃和浅色刀芯。普通非骑乘渲染保持原来的模式选择。
- 前三Boss及骑士全部原画库停用跨图片边界网格变形。`assets/animation/boss_scale_guides.json`记录8个库、288帧的身体标记和素材组参考帧；同组固定像素单位，举枪、披风张开、弯腰和马匹腾跃不会触发全身重缩放。祭主倒地/消散组按头部面积衔接，避免把跪姿强行放大到站姿高度。骑士的残影、兵器端点与地面补偿使用对应帧单位；强化枪只延伸外露枪杆。清除新骑士裁图中误收进来的邻格长枪碎片。
- 祭主环射、追踪、碎光雨、地面波、光束采用银紫薄雾、暖白光芯与方向拖尾；预兆聚在权杖端部。落光用渐亮细光束取代实心矩形。巨大月盘及归月剧情保留。
- 标记复现：先运行`.venv/bin/python tools/measure_boss_landmarks.py`，用`tools/run_visual_fixes_capture.py --study`检查标记；`tools/build_boss_scale_guides.py`包含人工复核修正和每素材组站姿参考帧，生成运行时比例JSON。该过程测量/裁切已有素材，不重新绘制角色。

### 验证

- `visual_fixes_regression.gd`：1467项通过。覆盖两种动画设置、两种骑乘形态、实际攻击输入、三连击兵器运动、座位固定、跨帧几何稳定、解剖参考尺度、强化枪不拉伸躯干。
- `hero_mount_polish.gd`：22项通过；体力、闪现/冲撞反馈及新骑乘渲染。
- `boss_reset_behavior.gd`：3124项通过；前三Boss调度、月亮形态和归月剧情。
- `boss_reset_knight.gd`：44项通过；现有骑士招式。
- `default_2d_ai_voice.gd`：13项通过；默认2D、默认AI及显式选择持久化。
- 后台静音实际渲染756帧，另补拍修正刀芯后的108帧骑乘部分；检查人形/羊灵三连击、祭主全部10招、骑士骑战/步战。预览：`builds/qa/visual-stability/visual-fixes.mp4`（25.2秒）；使用受控姿态采样，不等于一轮完整实战录像。
- 本轮没有重新打包或部署；之前构建的发布包尚未包含本轮视觉修正。
