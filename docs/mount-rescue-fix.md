# 牛大侠自动上牛修复

## 事实与根因
2026-10-25逐关复现：第1、2、3关 `become_demon()` 后 `is_carried()==true`；第4关为false。根因是骑士关资源 `no_carry=true`，使 `demon_controller.start()` 在已经变成牛魔后跳过 `player.attach_to()`。变身概率、坐骑骨架、坐姿对齐在普通关均正常。

## Mini Fix Contract
- 按用户本次修复要求，骑士关也恢复新变身时自动拉主角上牛，沿用既有骑乘时间、治疗、坐姿与下牛流程；不修改变身概率。
- 保留全场低位枪气必须跳跃躲避的要求。骑乘时按跳跃主动下牛并立即起跳；若仍骑在落地牛魔身上，枪气先打断骑乘，再按原伤害结算，不能靠牛背高度或保护状态逃避。
- 封葫芦立即下牛并保存助战血量、形态与时间。解除后不额外刷新骑乘、治疗、助战延时。
- 牛魔死亡、正常退场、重试和切关均能解除依附并恢复主角碰撞。

## 验证
逐关自动上牛、真实跳跃输入下牛、骑士枪气与尘气、封印恢复、牛魔原有治疗/骑乘时长、坐姿左右对齐。重新编译macOS和Web。
