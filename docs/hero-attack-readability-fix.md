# 羊小侠攻击动作可读性修正

## Observed Facts

- 战斗使用 `painted_rig/combo.gd`，身体旋转仅为原动作轨迹的 0.35 倍。
- 剑光只覆盖剑刃外侧 20%，透明度 0.18，残留 0.07 秒；缩到 52.8 像素角色尺寸后不易辨认。
- 关键帧截图显示第一、三段在命中后很快回到垂手姿态。
- 命中触发 hitstop 后，动画节点提前返回，无法立即显示玩家已推进到的命中姿势。

## Mini Fix Contract

- 加大三段攻击的蓄势、挥臂、躯干发力与跟随动作，并保持脚底和肘部连接稳定。
- 增宽、提亮剑刃轨迹，短暂保留收招剑光，剑身增加命中阶段高光。
- 命中停顿首次发生时同步实际命中姿势，停顿期间不继续推进动画或残影。
- 不改伤害、攻击范围、判定时刻、连击时序、移动数值和三套方向搓招。

## Verification

- 修改前后比较三段攻击关键帧，检查自然游戏尺寸及实际战斗截图。
- 检查关节与剑身刚性、剑光随显示姿势对齐、停顿冻结、普攻伤害与搓招回归。
- 导出 Mac 和 Web，并检查 Mac 编译产物启动。
