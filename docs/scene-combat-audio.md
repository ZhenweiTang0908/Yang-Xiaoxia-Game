# 场景配乐与战斗声音

四位 BOSS 的 AI 台词重新加入表演指导：守灯兽粗粝威严、刀客冷酷凌厉、祭主阴森宣判、骑士低沉有怒意；遗言允许虚弱，避免整句无差别怒吼。使用语音服务独立 instructions 字段，台词文字不混入指导。经典配音原件与设置选择保留。

八条短促发力声使用独立播放器，在突进/扑击/重招释放时触发，800ms 最短间隔，完整对白优先。无额外字幕；暂停与退出停止状态受游戏控制。原始响应超过短喊长度时，离线截取第一个发力音并淡出，最长 0.88 秒。

武器释放声从现有 CC0 原始破风录音重新制作，短刺、旋枪、重挑、刀斩各有声音；不加入空挥命中音。刀客三连斩与祭主四连斩在每次实际挥击时分别触发，避免只在连招开头响一次。

make_scene_score.py 生成八首原创合成配乐：山门钟音、第二关弦乐三拍、祭坛低音吟唱、骑士铜管战鼓。每关探索/战斗分别编曲，整小节循环，包含六小节乐句变化。第四关使用自己的曲目，不再跟随复用场景美术而沿用第三关音乐。维持原有交叉淡化、对白压低音乐和音量设置。

验证：scene_combat_audio.gd 覆盖八首音乐路由/循环、四位 BOSS 发力、节流、无字幕、对白优先、暂停恢复、退出停止、骑士蓄力与出手区别及破风资源。boss_dialogue.gd 覆盖双配音库和实际对白事件。额外复核箭伤害和战斗命中声音，避免音频优化影响平衡。
