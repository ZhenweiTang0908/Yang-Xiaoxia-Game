# 手柄控制

## 用户指定 Switch 布局（当前生效）

| Switch 印字 | 用户称呼 | 动作 |
|---|---|---|
| X | X | 冲刺 |
| A | A | 跳跃 |
| B | B | 召唤 |
| Y | Y | 变身 |
| L 短按松开 | LB | 近战 |
| L 持续按住，松开 | 长按 LB | 蓄力释放 |
| R | RB | 远程 |
| ZR | RT | 翻滚 |
| 十字键上 | 上键 | 使用月露（恢复最多 35 生命） |

L 在260ms内松开出近战，按住超过阈值且当前近战结束后进入蓄力。进入时计入预备蓄力量，避免刚跨过阈值释放却毫无反馈。暂停/断线取消蓄力，避免恢复时意外爆发。键盘 J 和 U 仍分开。Switch 菜单 A 确认、B 返回。

X 冲刺为快速平移，ZR 翻滚较短并有翻滚动作/无敌时间，二者共用位移冷却。旧版 controller.cfg（未标 layout/version=2）的键位不再覆盖本次明确指定的默认布局；新版自定义仍保存。当前默认按 Switch 印字确定物理位置，不套用 Xbox 字母。
标题页的操作说明支持改键，近战与长按蓄力共用同一按键；冲突时交换绑定。月露固定使用十字键上，不参与动作改键，HUD 会持续显示剩余数量。检测到 Switch Pro Controller，当前验证采用模拟输入，尚未由玩家实按验证本次布局。

本次验证：`tests/gamepad.gd`（19 项模拟输入检查）、`tests/moon_tonic.gd`（16 项）与 `tests/integration.gd`（53 项）通过；月露上键不会泄漏到近战或蓄力。实体手柄仍需玩家实按验收。
